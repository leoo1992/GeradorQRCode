# QR Code Generator

A web application that generates a QR code from text and reads a QR code from an uploaded image.

## Stack
- React
- Vite
- QR code generation and image/camera scanning libraries

The runnable project is inside `GeradorQRCode`:

```bash
cd GeradorQRCode
npm install
npm start
```
